# Project Report - Personal Expense Tracker

## Introduction
The Personal Expense Tracker is a beginner-friendly command-line Python application. Most of the complete program is kept in `main.py`.

## Objectives
1. Implement registration and login.
2. Maintain user-specific expense records.
3. Add, view, search, update and delete expenses.
4. Calculate totals and summaries.
5. Store data in simple text files.
6. Demonstrate seven course modules.

## Module Mapping
- Module 2: variables, strings and basic Python structures.
- Module 3: arithmetic, comparison and logical operators.
- Module 4: input/output using input(), print(), open(), read() and write().
- Module 6: int and float conversion.
- Module 7: lists, dictionaries and tuples.
- Module 8: if/elif/else, for and while.
- Module 9: reusable functions.

## Program Flow
Start -> Register/Login/Exit -> Login -> Expense Menu -> Operation -> Save -> Logout.

## Testing
Basic unit tests check total, average and expense data handling.

## Limitations
Plain-text passwords are used for this educational project to keep the implementation within the selected beginner modules. Production applications require secure password storage.

## Future Scope
Database storage, password hashing, GUI, budgets and charts.

## Conclusion
The project combines seven Python Essentials modules into a practical and readable CLI application.
