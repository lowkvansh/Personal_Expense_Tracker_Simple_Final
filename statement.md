# Project Statement

## Title
Personal Expense Tracker

## Problem
Manual expense records can make it difficult to calculate total spending and understand categories.

## Objective
Create a simple Python CLI with Register, Login, Exit and personal expense management.

## Features
Register, Login, Logout, Exit, Add, View, Search, Update, Delete, Total, Average, Category Summary and Monthly Summary.

## Modules
Modules 2, 3, 4, 6, 7, 8 and 9.

## Storage
Simple text files using Python file input/output.
